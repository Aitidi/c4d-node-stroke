# NodeStroke 使用文档

[English](usage.md) | 简体中文

NodeStroke 让你在 Cinema 4D 节点编辑器里按住一个键划线，给 Redshift 节点材质连线、断线。

**运行环境**：Windows，Redshift 节点材质，Cinema 4D 2027+ 或 2026+。2026 的不同之处见 [Cinema 4D 2026](#12-cinema-4d-2026)。

## 1. 安装

1. 关闭 Cinema 4D。
2. 解压对应版本的下载包：2027 用 `NodeStroke-C4D2027.zip`，2026 用 `NodeStroke-C4D2026.zip`。里面是一个 `NodeStroke` 文件夹，含 `nodestroke.xdl64`、`res` 文件夹和 `README.txt`。
3. 把整个文件夹复制到用户插件目录 `%APPDATA%\Maxon\Maxon Cinema 4D <版本>_<id>\plugins\`（编辑 > 设置，左下角“打开偏好设置文件夹”可以找到）。也可以放到程序目录下的 `plugins`，但需要管理员权限。
4. 启动 Cinema 4D，会出现 **扩展 > NodeStroke** 菜单和 **编辑 > 设置 > NodeStroke** 页面。

只装一份，装两份的话每个手势都会执行两次。

**更新**：关闭 C4D，替换文件夹。**卸载**：关闭 C4D，删除文件夹。连接规则保存在偏好设置文件夹的 `nodestroke_rules.txt`，不需要的话一并删除。

## 2. 快速上手

1. 在节点编辑器中打开一个 Redshift 节点材质。
2. 鼠标放在画布上，**按住 I**，从一个节点移过另一个节点，松开 I：两个节点连上了。
3. **按住 Y**，移过一条连线，松开 Y：连线被切断。

按住 I 和 Y 时不用按鼠标键。移动时显示笔画，松开按键时执行，每次操作是一步撤销。

## 3. 连接：按住 I

按住 **I**，划过要连接的节点，然后松开。

- **顺序**：按划过的顺序依次连成一串：第一个 → 第二个 → 第三个。
- **指定端口**：从第一个节点的输出端口行开始、在最后一个节点的输入端口行结束，就用这两个端口。从标题或缩略图开始或结束，则由 NodeStroke 自动选择（见[端口是怎么选的](#8-端口是怎么选的)）。
- **输入已被占用**：新连线替换旧连线。
- **找不到合适的输入**：两个节点之间会弹出目标节点的输入菜单，选一个即可，关闭菜单则取消。
- **UV Context Projection**：从这个节点开始的笔画，会把它连到划过的每个节点的 UV Context 输入。
- **节点组**：组内可以划线，组视图两侧面板的组接口端口也可以作为起点或终点。

结果显示在状态栏，例如“NodeStroke：已连接 3 个节点。”

## 4. 切断：按住 Y

按住 **Y**，划过要删除的连线，然后松开。笔画穿过的连线全部切断，包括连到组接口端口的连线。没有穿过任何连线时状态栏会提示。

## 5. 摇晃节点断开连线

拖动节点时左右快速摇晃（大约换四次方向）。NodeStroke 把它从连线中取出，并在类型匹配时把上游直接接到下游。选中了多个节点时，全部取出。

## 6. 把节点拖到连线上插入

把一个没有连线的节点拖到连线上，停留约三分之一秒再松开，节点会用兼容的端口插入这条线。已有连线的节点不会被插入，拖着它经过其他连线不会误改。

## 7. 自动添加 Bump Map 和 Displacement 节点

| 连到 | NodeStroke 自动添加 |
| --- | --- |
| Standard Material 的 Bump 输入，或 OpenPBR 材质的 Geometry Normal 输入 | **Bump Map** 节点 |
| Output 节点的 Displacement 输入 | **Displacement** 节点 |

新节点加在来源和目标之间，放在来源右边一个节点的位置；上游已有这种节点时不再添加。连线和加节点是一步撤销。

## 8. 端口是怎么选的

**划线（按住 I）：**

1. 笔画起点和终点下方的端口。
2. 这两种节点之间的[连接规则](#9-连接规则)。
3. 目标节点上从上到下第一个空闲且能连的输入。
4. 弹出目标节点的输入菜单（两个节点之间），串连多个节点时自动选择。

想连到某个特定输入，就让笔画结束在那一行上。

**命令（依次连接、从最左节点分发、汇入最右节点）：** 先用连接规则，再找同类型族（如 col3/col4）的空闲输入，再找任意能连的空闲输入，最后替换已占用的输入（汇入最右节点不替换）。

## 9. 连接规则

一条规则的意思是：“把 A 类节点连到 B 类节点时，用这个输出和这个输入。”规则优先于自动选择。

**编辑 > 设置 > NodeStroke > 编辑规则...** 打开规则窗口，每行显示“来源节点 / 输出端口 → 目标节点 / 输入端口”。

- **从选中端口添加**：在节点编辑器里选中一个输出端口和一个输入端口，再点这个按钮。两个端口会被连上并保存为规则。
- **删除**：删除选中的规则。
- **重新载入**：手动改过文件后重新读取。
- **打开规则文件...**：打开 `nodestroke_rules.txt`。每行格式为 `<来源资产 ID> <输出端口 ID> <目标资产 ID> <输入端口 ID>`，`#` 开头的行是注释。

## 10. 菜单与命令

**扩展 > NodeStroke** 里有两个命令：

- **NodeStroke** 开启或关闭所有手势，开启时显示勾选。
- **NodeStroke 设置...** 打开设置页。

Boghma 等插件管理器如果列出了 NodeStroke，也会显示同样的命令和图标。

下面的命令在**命令管理器**（Shift+C，搜索“NodeStroke”）里，可在 **窗口 > 自定义 > 自定义命令** 里设置快捷键。执行前先在材质管理器中选中节点材质，再在节点图里选中要操作的元素。

| 命令 | 作用 |
| --- | --- |
| 连接所选端口 | 把选中的一个输出端口连到选中的一个输入端口 |
| 断开所选节点 | 删除所选节点的全部连线 |
| 删除所选连线 | 删除选中的连线 |
| 抽出所选节点 | 把所选节点从连线中取出（与摇晃相同） |
| 依次连接所选节点 | 把所选节点从左到右连起来 |
| 从最左节点分发 | 把最左边的节点连到其他每个所选节点 |
| 汇入最右节点 | 把其他所选节点连到最右边节点的空闲输入 |
| 把节点插入所选连线 | 把选中的节点插入选中的连线（也可选中连线两端的节点和要插入的节点） |
| 从所选端口添加规则 | 连接选中的一对端口并保存为规则 |
| 编辑连接规则 | 打开规则窗口 |

## 11. 设置

**编辑 > 设置 > NodeStroke**：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 启用手势 | 开 | 总开关，与 扩展 > NodeStroke 相同 |
| 按住 I 绘制连接 | 开 | 第 3 节 |
| 按住 Y 切断连线 | 开 | 第 4 节 |
| 摇晃节点断开连线 | 开 | 第 5 节 |
| 拖到连线上插入节点 | 开 | 第 6 节 |
| 编辑规则... | | 第 9 节 |
| 写入诊断日志 | 关 | 把手势没有生效的原因写入偏好设置文件夹的 `nodestroke_debug.txt` |

如果某个按键和你的快捷键冲突，可以在这里关掉对应手势。界面跟随 C4D 界面语言（英文或简体中文）。

## 12. Cinema 4D 2026

- **先滚动一次画布**：第一次划线前，用滚轮或鼠标中键在画布上滚动一次。之后如果按住 I 或 Y 没有笔画（比如双击进入组之后），再滚动一次。
- **2026.4.0**：其余功能与 2027 一致，包括精确端口和组接口端口。
- **2026.4.0 之前的版本**：位置为估算，连到组接口端口的连线无法连接或切断。

详见 [Cinema 4D 2026 适配](compatibility-2026.zh-CN.md)。

## 13. 常见问题

**划了没反应。** 先看状态栏。确认鼠标在节点编辑器画布上，且编辑器显示的是材质管理器里当前选中的材质。2026 上先滚动一次画布。

**提示“无法识别这个节点编辑器”。** 在材质管理器里选中编辑器显示的材质再试。2026 上先滚动一次画布再划线。

**连到了不想要的端口。** 让笔画结束在想要的输入端口行上，或添加一条连接规则。

**还是不行。** 打开**写入诊断日志**，重复一次手势，把偏好设置文件夹里的 `nodestroke_debug.txt` 和问题描述一起发给我们。排查完把日志关掉。
