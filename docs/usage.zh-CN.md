# NodeStroke 使用文档

[English](usage.md) | 简体中文

NodeStroke 让你在 Cinema 4D 节点编辑器里，按住一个键再移动鼠标划线，就能给 Redshift 节点材质连线、断线。本文介绍安装方法、每种手势、连接规则、命令和设置。

**运行环境**：Windows，Cinema 4D 2027.0，Redshift 节点材质。

## 1. 安装

1. 关闭 Cinema 4D。
2. 解压 `NodeStroke.zip`，里面是一个 `NodeStroke` 文件夹，含 `nodestroke.xdl64`、`res` 文件夹和 `README.txt`。
3. 把整个 `NodeStroke` 文件夹复制到 Cinema 4D 的插件目录，二选一：
   - 用户插件目录：`%APPDATA%\Maxon\Maxon Cinema 4D 2027_<id>\plugins\`（编辑 > 设置，左下角“打开偏好设置文件夹”可以找到）；
   - 程序插件目录：`C:\Program Files\Maxon Cinema 4D 2027\plugins\`（需要管理员权限）。
4. 启动 Cinema 4D。**编辑 > 设置** 里会多出 **NodeStroke** 页面。

只在一个位置安装。装两份的话，每个手势都会被执行两次。

**更新**：关闭 Cinema 4D，用新的 `NodeStroke` 文件夹替换旧的。
**卸载**：关闭 Cinema 4D，删除 `NodeStroke` 文件夹。连接规则保存在偏好设置文件夹的 `nodestroke_rules.txt` 里，卸载不会删掉它，不需要的话可以一并删除。

## 2. 快速上手

1. 在节点编辑器中打开一个 Redshift 节点材质。
2. 把鼠标放在画布上，**按住 I**，从一个节点移过另一个节点，松开 I：两个节点连上了。
3. **按住 Y**，把鼠标移过一条连线，松开 Y：这条线被切断了。

按住 I 和 Y 时不用按鼠标键，只是按住按键移动鼠标。移动时画布上会显示笔画，松开按键时才执行。每次操作都是一步撤销，按 **Ctrl+Z** 就能撤回。

## 3. 连接：按住 I

按住 **I**，划过要连接的节点，松开 **I**。

- **两个节点**：先划过的是来源，后划过的是目标。
- **多个节点**：按划过的顺序依次连成一串：第一个 → 第二个 → 第三个……
- **指定端口**：笔画从第一个节点的某个输出端口行开始，在最后一个节点的某个输入端口行结束，就会用这两个端口。如果从节点的其他位置（标题、缩略图）开始或结束，端口由 NodeStroke 自动选择（见[端口是怎么选的](#8-端口是怎么选的)）。
- **输入端口已被占用**：新连线会替换原来的连线。
- **找不到合适的输入**：两个节点之间的笔画会弹出目标节点的输入端口菜单，选一个即可；关闭菜单则取消。
- **UV Context Projection**：从 UV Context Projection 节点开始的笔画，会把它连到划过的每个节点的 UV Context 输入，比如一笔就能连上所有贴图。
- **节点组**：在节点组里面也能用；组视图两侧面板里的组接口端口也可以作为起点或终点，把组的输入、输出连到组内节点。

结果会显示在状态栏，例如“NodeStroke：已连接 3 个节点。”

## 4. 切断：按住 Y

按住 **Y**，划过要删除的连线，松开 **Y**。笔画穿过的所有连线都会被切断，算一步撤销。如果笔画没有穿过任何连线，状态栏会提示，不做任何修改。连到组接口端口的连线也能切断。

## 5. 摇晃节点断开连线

像平常一样用鼠标左键拖动一个节点，同时左右快速摇晃（大约来回换四次方向）。NodeStroke 会把这个节点从它的所有连线中取出，并在类型匹配时，把它的上游直接接到下游。

如果选中了多个节点、拖动的是其中一个，所有选中的节点都会被取出。

## 6. 把节点拖到连线上插入

把一个没有任何连线的节点拖到一条已有的连线上，停留一下（约三分之一秒）再松开鼠标。节点会被插入这条线：连线的来源接到节点的输入，节点的输出接到连线的目标，自动选择兼容的端口。

只有没有连线的节点才会被插入，所以拖着已连好的节点经过其他连线时，不会被意外改线。

## 7. 自动添加 Bump Map 和 Displacement 节点

在 Redshift 里，有些输入需要一个中间节点。NodeStroke 会替你加上：

| 连到 | NodeStroke 自动添加 |
| --- | --- |
| Standard Material 的 Bump 输入，或 OpenPBR 材质的 Geometry Normal 输入 | 在来源和材质之间加一个 **Bump Map** 节点 |
| Output 节点的 Displacement 输入 | 在来源和 Output 之间加一个 **Displacement** 节点 |

如果来源上游已经有这种节点，就不会再加。如果贴图文件名表明它是法线贴图（例如 `wood_normal.png`），Bump Map 节点会设为切线空间法线；其他来源设为高度场。

新节点会放在来源节点右边一个节点的位置，与来源节点平齐；如果会挡住别的节点，会上下稍微挪开。连线和添加节点合起来是一步撤销。

## 8. 端口是怎么选的

当笔画不是从端口行开始或结束时，NodeStroke 按下面的顺序选端口：

1. 笔画起点和终点下方的**指定端口**。
2. 这两种节点之间的**连接规则**（见下节）。
3. 目标节点上**第一个空闲且能连的输入**，按节点上显示的顺序从上到下。
4. 根据来源判断的 **Redshift 工作流规则**。贴图按文件名里的关键词识别：

   | 文件名包含 | 连到 |
   | --- | --- |
   | `normal`、`nrm`、`_nor` | Bump（经过 Bump Map 节点） |
   | `disp` | Output 的 Displacement（经过 Displacement 节点） |
   | `bump`、`height` | Bump（经过 Bump Map 节点） |
   | `rough`、`gloss` | 反射粗糙度 / 高光粗糙度 |
   | `metal` | 金属度 |
   | `opac`、`alpha`、`mask`、`transp` | 不透明度 |
   | `emis`、`emit`、`glow` | 自发光颜色 |
   | `occlusion`、`_ao`、`ao_`、`ambient` | Overall Color（Standard Material） |
   | `spec`、`refl` | 反射颜色 / 高光颜色 |
   | 其他 | 基础颜色 |

   材质会连到 Output 的 Surface 输入。

5. 弹出目标节点的**输入菜单**（只在两个节点之间的笔画时出现）。

## 9. 连接规则

一条规则的意思是：“把 A 类节点连到 B 类节点时，用这个输出和这个输入。”规则优先于自动选择。

**编辑 > 设置 > NodeStroke > 编辑规则...** 打开规则窗口：

- 每行一条规则，显示为“来源节点 / 输出端口 → 目标节点 / 输入端口”，名称跟随 Cinema 4D 的界面语言。
- **从选中端口添加**：先在节点编辑器里选中一个输出端口和一个输入端口，再点这个按钮。两个端口会被连上，并记为这两种节点之间的规则。
- **删除**：选中一条或多条规则后删除。
- **重新载入**：手动改过规则文件后，重新读取。
- **打开规则文件...**：用文本编辑器打开 `nodestroke_rules.txt`。每行格式为 `<来源节点资产 ID> <输出端口 ID> <目标节点资产 ID> <输入端口 ID>`，以 `#` 开头的行是注释。

## 10. 命令与快捷键

这些命令不在扩展菜单里。可以在**命令管理器**（Shift+C）里搜索“NodeStroke”，或在 **窗口 > 自定义 > 自定义命令** 里给它们设置快捷键。

执行命令前，先在材质管理器中选中节点材质，再在节点图里选中要操作的元素。

| 命令 | 作用 |
| --- | --- |
| 连接所选端口 | 把选中的一个输出端口连到选中的一个输入端口 |
| 断开所选节点 | 删除所选节点的全部连线 |
| 删除所选连线 | 删除选中的连线 |
| 抽出所选节点 | 把所选节点从连线中取出（与摇晃相同） |
| 依次连接所选节点 | 把所选节点按从左到右的顺序连起来 |
| 从最左节点分发 | 把最左边的所选节点连到其他每个所选节点 |
| 汇入最右节点 | 把其他所选节点连到最右边那个节点的空闲输入 |
| 把节点插入所选连线 | 把选中的节点插入选中的连线（也可以选中连线两端的节点和要插入的节点） |
| 从所选端口添加规则 | 连接选中的一对端口，并保存为规则 |
| 编辑连接规则 | 打开规则窗口 |
| 开关画布手势 | 一键开启或关闭所有手势 |

## 11. 设置

**编辑 > 设置 > NodeStroke**：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 启用手势 | 开 | 下面所有手势的总开关 |
| 按住 I 绘制连接 | 开 | 第 3 节 |
| 按住 Y 切断连线 | 开 | 第 4 节 |
| 摇晃节点断开连线 | 开 | 第 5 节 |
| 拖到连线上插入节点 | 开 | 第 6 节 |
| 编辑规则... | | 打开规则窗口（第 9 节） |
| 写入诊断日志 | 关 | 把手势没有生效的原因写入偏好设置文件夹的 `nodestroke_debug.txt` |

如果 I 或 Y 和你自己的快捷键冲突，可以在这里关掉对应的手势。插件界面跟随 Cinema 4D 的界面语言（英文或简体中文）。

## 12. 常见问题

**划了没反应。** 先看状态栏，大多数情况 NodeStroke 会在那里说明原因，比如笔画只碰到了一个节点。确认鼠标在节点编辑器的画布上，并且编辑器显示的是材质管理器里当前选中的材质。

**提示“无法识别这个节点编辑器”。** 在材质管理器里选中这个编辑器显示的材质，然后重试。如果用的不是 Cinema 4D 2027.0，插件拿不到精确位置：先用滚轮滚动一次画布，再划线。

**连到了不想要的端口。** 让笔画正好结束在想要的输入端口行上，或者给这两种节点添加一条连接规则。

**还是不行。** 打开**写入诊断日志**，重复一次手势，然后把偏好设置文件夹里的 `nodestroke_debug.txt` 和问题描述一起发给我们。排查完记得把日志关掉。
